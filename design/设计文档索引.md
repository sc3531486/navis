# Navis 与 Navis Code 设计文档索引

> **设计准则**：
> 1. **Navis**（`design/navis/`）：**100% 纯净框架底座**。通用桌面应用白板与扩展运行时底座，负责生命周期、Cordis 容器、动态插槽、IPC 路由、流式通道与系统级服务（通知、快捷键、i18n、剪贴板），不含任何特定产品或 AI 业务逻辑。
> 2. **Navis Code**（`design/naviscode/`）：**AI Agent IDE 产品套件**。基于 Navis 框架装配的第一个产品形态，包含 Agent 执行流、模型网关、会话、代码编辑器、终端、Token 上下文、MCP/LSP、Agent 安全沙箱与工具确认等全套业务套件设计。
