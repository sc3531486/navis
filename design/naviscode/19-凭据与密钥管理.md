# 06 — 身份鉴权与凭据管理详细设计（Authentication & Credentials）

> 模块编号：06 | 模块归属：Navis 通用宿主底座 / 安全层  
> 依赖：01-日志服务, 04-存储系统  
> 被依赖：AI 网关、Git 扩展、第三方服务集成、安全沙箱

---

## 一、模块概述与定位

### 1.1 定位
Auth 是 Navis 宿主的**凭据事实源与安全保管箱**，负责所有需要保密的外部敏感凭据：模型提供商 API Key、Git 凭据、第三方服务 Token 以及扩展所需的私有密钥。

### 1.2 核心安全原则
1. **不透明引用（Opaque Reference）**：UI、日志、配置清单与扩展通信一律只传递引用 ID（`secret:<id>`），绝不暴露明文。
2. **最小暴露时间（Ephemeral Access）**：明文仅在受控后端端口执行网络请求的瞬时于内存中解密。
3. **零化清理（Zeroization）**：临时明文密钥在用完释放（Drop）时自动将内存覆写为 0。

---

## 二、架构设计与 SecretResolver 端口

```rust
pub struct SecretReference {
    pub id: String,          // opaque ID
    pub owner_scope: String, // provider:<id> / extension:<id> / git:<id>
    pub kind: String,        // bearer / api-token / ssh-key / custom
    pub label: String,       // UI 展示名称，不包含明文
}

pub trait SecretResolver: Send + Sync {
    fn resolve(&self, reference: &SecretReference) -> Result<ZeroizingString, AuthError>;
}
```
