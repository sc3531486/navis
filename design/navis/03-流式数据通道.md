# 03 — 流式数据通道详细设计（Stream Channels & Push Engine）

> 模块编号：03 | 模块归属：Navis 通用宿主底座 / 通信层  
> 依赖：Tauri 2 Channel, Tokio MPSC  
> 被依赖：AI 网关、Agent 执行流、PTY 终端面板、所有流式扩展

---

## 一、模块概述与核心定位

### 1.1 定位
Stream 模块是 Navis 所有流式数据通信的**唯一出口与标准通道**。它封装了 Tauri 2 原生 `Channel<T>` API、Tokio MPSC 异步通道与节流发射器，为大模型 Token 逐字流、终端高频输出等连续数据流提供统一的高性能接入层。

### 1.2 职责边界
```text
负责：
├── 跨进程流式通道（基于 Tauri 2 Channel<T> 与 Tokio MPSC 异步通道）
├── 高频数据节流与缓冲合并（ThrottledEmitter，默认 50ms 聚合窗口）
├── 全局活跃流生命周期管理、超时取消与优雅关闭
└── 前端流订阅规范与响应式 Channel 消费

不负责：
├── 离散非流式 RPC 命令（由 02-进程间通信 承接）
└── 模型协议转换与 Framing（属于 AI 网关内部逻辑）
```

## 二、通信协议与交互接口

### 2.1 前端流订阅接口（`src/core/tauri-bridge.ts`）

```typescript
import { Channel } from '@tauri-apps/api/core';
import { invoke } from '@tauri-apps/api/core';

/** 流式 Channel 调用：订阅插件后端进程的流式推送 */
export async function coreRouteStream<T = any>(
  pluginId: string,
  method: string,
  params: Record<string, any>,
  onEvent: (event: T) => void,
): Promise<void> {
  const channel = new Channel<T>();
  channel.onmessage = onEvent;
  return invoke('core_route_stream', { pluginId, method, params, onEvent: channel });
}
```

### 2.2 后端 Rust 流式转发（`src-tauri/src/core/ipc_bridge.rs`）

```rust
#[tauri::command]
pub async fn core_route_stream(
    transport: State<'_, Arc<TransportRouter>>,
    plugin_id: String,
    method: String,
    params: Value,
    on_event: tauri::ipc::Channel<Value>,
) -> Result<(), String> {
    transport.stream_rpc(&plugin_id, &method, params, on_event).await
}
```
